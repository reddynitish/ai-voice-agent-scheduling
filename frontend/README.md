# Web UI

Next.js voice interface for Ava, based on LiveKit's [agent-starter-react](https://github.com/livekit-examples/agent-starter-react) (MIT, see `LICENSE`).

Changes from the template: scheduling-specific welcome screen, explicit dispatch of the `scheduler` agent, a rate-limited token route that is safe to expose publicly, error toasts when a call can't start, and standalone build output for self-hosting.

See the [root README](../README.md) for setup.
